# 팝업 설정 사용자 가이드

## 1. 문서 목적

이 문서는 관리자 화면에서 팝업을 등록하거나 수정하는 사용자를 위한 설정 설명서다.

내부 클래스나 DB 컬럼보다는 실제 화면에서 어떤 값을 선택할 수 있고, 선택했을 때 사용자 PC의 WPF 팝업이 어떻게 동작하는지를 중심으로 설명한다.

현재 팝업 유형은 다음 다섯 가지다.

- TEXT: 일반 안내문
- IMAGE: 이미지 안내
- VIDEO: 영상 안내/교육
- SURVEY: 설문
- QUIZ: 퀴즈/평가

---

## 2. 공통 설정

### 2.1 기본 정보

| 화면 항목 | 실제 값 | 설명 |
|---|---|---|
| 팝업 ID | `popupId` | 팝업을 구분하는 고유값. 저장 후 변경하지 않는 것을 권장 |
| 팝업 제목 | `title` | 사용자 팝업 상단 Header에 표시되는 제목 |
| 팝업 유형 | `TEXT`/`IMAGE`/`VIDEO`/`SURVEY`/`QUIZ` | 팝업 콘텐츠 형태 |
| 노출 시작 | `displayStartAt` | 이 시각 이후부터 조회 대상 |
| 노출 종료 | `displayEndAt` | 이 시각 이후에는 더 이상 조회되지 않음 |
| 팝업 활성화 | active | 켜져 있어야 사용자 조회 대상이 됨 |

### 2.2 표시 방식

| 화면 선택 | 실제 값 | 동작 |
|---|---|---|
| 순차 표시 | `SEQUENTIAL` | 같은 우선순위 팝업을 한 개씩 표시 |
| 동시 표시 | `SIMULTANEOUS` | 같은 우선순위의 팝업을 여러 창으로 동시에 표시 |

### 2.3 표시 우선순위

`displayOrder` 숫자가 작을수록 먼저 표시된다.

예:

```text
10 → 먼저 표시
20 → 10번 그룹이 끝난 뒤 표시
30 → 그 다음 표시
```

같은 번호의 팝업은 하나의 표시 그룹이 된다.

예:

```text
팝업 A: displayOrder 10 / SIMULTANEOUS
팝업 B: displayOrder 10 / SIMULTANEOUS
→ A와 B 동시 표시

팝업 C: displayOrder 20
→ 10번 그룹 종료 후 표시
```

## 3. 노출 대상 설정

관리자 화면에서는 대상 그룹과 조건을 만들 수 있다.

같은 그룹 안의 조건은 모두 만족해야 하고, 서로 다른 그룹끼리는 하나만 만족해도 된다.

```text
그룹 내부 = AND
그룹 사이 = OR
```

현재 선택 가능한 조건은 다음과 같다.

| 조건 | 설명 |
|---|---|
| 부서 | 특정 부서 대상. 하위 부서 포함 가능 |
| 직급 | 특정 직급 대상 |
| 사번 | 특정 사용자 대상 |
| 입사일 | 특정 날짜와 비교 |

입사일은 같음/같지 않음/이전/이전 또는 당일/이후/이후 또는 당일 비교를 사용할 수 있다.

## 4. 팝업 크기

### 4.1 고정 크기

화면 선택: `고정 크기`

팝업 너비와 높이를 픽셀로 직접 지정한다.
입력값은 설정된 최소/최대 범위 안으로 자동 보정된다.

### 4.2 화면 비율

화면 선택: `화면 비율`

현재 모니터 크기에 비례해 팝업 크기를 계산한다.

예:

```text
너비 비율 0.7
높이 비율 0.75
```

이면 모니터 작업 영역의 약 70% × 75% 크기로 표시된다.

> 현재 관리자 화면/서버 값과 WPF 내부 문자열 이름이 서로 다른 부분이 있어 별도 정리 대상이다. 실제 운영 반영 전 개발 문서의 호환성 항목을 확인한다.

### 4.3 전체 화면

화면 선택: `전체 화면`

팝업이 표시되는 모니터 전체를 사용한다.
일반 팝업의 고정 너비/높이 값은 사용하지 않는다.

### 4.4 자동 크기

WPF에는 콘텐츠 크기에 맞춰 창 크기를 정하는 `AUTO` 기능이 구현되어 있지만 현재 관리자 화면에서는 선택할 수 없다.

## 5. 공통 화면 표시 옵션

| 화면 옵션 | 설명 |
|---|---|
| 헤더 표시 | 상단 제목 영역 표시 |
| 닫기 표시 | 닫기 버튼 표시 |
| 푸터 표시 | 하단 영역 표시 |
| 다시 보지 않기 | 사용자가 일정 기간 팝업을 숨길 수 있는 체크박스 표시 |

주의사항:

- 헤더를 끄면 상단 X 버튼도 보이지 않는다.
- 푸터를 끄면 다시 보지 않기 체크박스도 사용할 수 없다.
- 현재 WPF의 다시 보지 않기 기간은 30일 고정이다.

## 6. TEXT 팝업

TEXT는 단순 공지부터 카드형 안내, Markdown 문서까지 구성할 수 있다.

### 6.1 선택 가능한 구성

| 화면 기능 | 설명 |
|---|---|
| 콘텐츠 제목·설명 | 팝업 내부 제목과 설명 표시 |
| 일반 텍스트 | 자유 본문 영역 |
| 왼쪽 카드 | 왼쪽 카드 제목/본문 |
| 오른쪽 카드 | 오른쪽 카드 제목/본문/추가 설명 |
| 강조 문구 | 눈에 띄는 강조 영역 |
| 하단 설명 | 카드 아래 추가 문장 |
| Markdown 모드 | Markdown 문법으로 본문 구성 |

Markdown 모드를 켜면 일반 텍스트/카드형 구성보다 Markdown 내용을 중심으로 편집한다.

예:

```markdown
# 공지사항

중요한 내용은 **굵게 표시**할 수 있습니다.

- 안내 1
- 안내 2
```

## 7. IMAGE 팝업

### 7.1 기본 항목

| 화면 항목 | 설명 |
|---|---|
| 콘텐츠 제목 | 이미지 위/주변 제목 |
| 설명 | 이미지 설명 |
| 이미지 URL | 표시할 이미지 주소 |
| 클릭 연결 URL | 이미지 클릭 시 열 URL |
| 이미지 설명 표시 | 설명 노출 여부 |

### 7.2 이미지 크기 모드

| 선택 | 설명 |
|---|---|
| 고정 영역 | 지정한 영역을 기준으로 표시 |
| 원본에 맞춤 | 이미지 원본 비율/크기를 기준으로 계산 |
| 화면에 맞춤 | 이미지 형태와 화면 크기에 맞게 조정 |
| 꽉 채우기 | 제목/설명 영역 없이 이미지 중심으로 꽉 채워 표시 |

`꽉 채우기`는 이미지와 클릭 링크 중심의 전용 화면을 사용한다.

## 8. VIDEO 팝업

### 8.1 기본 설정

| 화면 항목 | 설명 |
|---|---|
| 콘텐츠 제목 | 영상 내부 제목 |
| 설명 | 영상 설명 |
| 영상 URL | 재생할 영상 주소/경로 |
| 완료 비율 | 전체 영상 중 몇 %를 시청해야 완료로 인정할지 지정 |
| 기본 음량 | 0~1 사이 값 |

### 8.2 선택 기능

| 기능 | 설명 |
|---|---|
| 영상 설명 표시 | 영상 설명 영역 표시 |
| 컨트롤 표시 | 재생 컨트롤 표시 여부 |
| 전체화면 허용 | 영상 자체 전체화면 사용 허용 |
| 배속 변경 허용 | 사용자의 재생속도 변경 허용 |
| 자동 재생 | 팝업이 열리면 자동 재생 |
| 반복 재생 | 종료 후 반복 |
| 완료 전 닫기 허용 | 완료 기준을 채우기 전에 창을 닫을 수 있는지 결정 |

`완료 전 닫기 허용`을 끄면 완료 비율을 충족하기 전 닫기를 제한한다.

WPF는 영상의 현재 위치뿐 아니라 실제 시청시간과 최대 도달 위치를 서버에 저장하고, 서버의 완료 판정을 사용한다.

## 9. SURVEY 팝업

SURVEY는 질문을 추가하고 사용자의 응답을 서버에 저장하는 팝업이다.

현재 관리자 화면에서 선택 가능한 문항 유형은 다음과 같다.

| 문항 유형 | 설명 |
|---|---|
| 객관식 · 단일 선택 | 하나만 선택 |
| 객관식 · 복수 선택 | 여러 개 선택 |
| 주관식 | 직접 텍스트 입력 |

각 문항은 다음 값을 설정할 수 있다.

- 문항 제목
- 문항 설명
- 필수 문항 여부
- 선택지

### 9.1 5점 평가

WPF에는 `RATING5` 기능이 구현되어 있어 1~5점 선택 UI를 표시할 수 있다.

하지만 현재 관리자 문항 유형 선택에는 5점 평가가 없으므로 관리자 화면에서 신규 설정할 수 없다.

---

## 10. QUIZ 팝업

QUIZ는 SURVEY와 같은 질문 화면을 사용하지만 채점 기능이 추가된다.

설정 가능한 항목은 다음과 같다.

- 문항 제목/설명
- 필수 문항
- 문항별 배점
- 객관식 정답 선택
- 주관식 정답
- 주관식 정답 비교 방식
- 통과 점수

주관식 정답 비교 방식:

| 선택 | 설명 |
|---|---|
| 정확히 일치 | 입력값이 정답과 같아야 함 |
| 포함 | 입력값에 정답 문자열이 포함되는지 확인 |

최종 점수와 통과 여부는 WPF에서 임의 확정하지 않고 서버 응답을 기준으로 처리한다.

## 11. 사용자가 팝업에서 수행하는 동작과 서버 처리

### 팝업 열기

```text
사용자 팝업 목록 조회
→ 표시 대상/기간/숨김 상태 확인
→ WPF 표시
→ DISPLAYED 이벤트 저장
```

### 팝업 닫기

```text
닫기
→ CLOSED 이벤트 저장
```

### 다시 보지 않기

```text
다시 보지 않기 체크
→ 닫기
→ 서버에 사용자 + 팝업 ID + 숨김 기간 저장
```

현재 WPF는 30일을 사용한다.

### 설문/퀴즈 제출

```text
답안 입력
→ 제출
→ 서버 저장/채점
→ 서버 결과 반환
```

### 영상 재생

```text
재생
→ 위치/누적 시청시간 측정
→ 서버 진행률 저장
→ 완료 기준 판정
```

## 12. 기능별 지원 현황 한눈에 보기

공통 기능과 팝업 유형별 개별 기능을 하나의 표에서 구분해 확인할 수 있다.

| 대분류 | 그룹 | 기능 | TEXT | IMAGE | VIDEO | SURVEY | QUIZ |
|---|---|---|:---:|:---:|:---:|:---:|:---:|
| **공통** | 헤더 | 헤더 표시 | O | O | O | O | O |
|  |  | 닫기 버튼 표시 | O | O | O | O | O |
|  | 푸터 | 푸터 표시 | O | O | O | O | O |
|  |  | 다시 보지 않기 표시 | O | O | O | O | O |
|  | 표시 방식 | 순차 표시 | O | O | O | O | O |
|  |  | 동시 표시 | O | O | O | O | O |
|  | 크기 | 고정 크기 | O | O | O | O | O |
|  |  | 화면 비율 | O* | O* | O* | O* | O* |
|  |  | 전체 화면 | O | O | O | O | O |
| **개별 기능** | TEXT | Markdown | O | - | - | - | - |
|  | IMAGE | 이미지 크기 모드 | - | O | - | - | - |
|  | VIDEO | 영상 완료 조건 | - | - | O | - | - |
|  | SURVEY/QUIZ | 단일 선택 | - | - | - | O | O |
|  |  | 복수 선택 | - | - | - | O | O |
|  |  | 주관식 | - | - | - | O | O |
|  |  | 답안 제출 | - | - | - | O | O |
|  |  | 5점 평가 | - | - | - | WPF O / 관리자 UI X | WPF O / 관리자 UI X |
|  | QUIZ | 채점 | - | - | - | - | O |
|  |  | 통과 점수 | - | - | - | - | O |

`*` 화면 비율은 현재 관리자/서버/WPF 문자열 명칭 정리가 필요하다.

표의 `O`는 해당 팝업 유형에서 지원되는 기능을 의미하며, `-`는 해당 유형에 적용되지 않는 기능을 의미한다.
`WPF O / 관리자 UI X`는 WPF 실행 기능은 구현되어 있지만 현재 관리자 화면에서는 직접 설정할 수 없음을 의미한다.

## 13. 현재 관리자 화면에서 바로 설정할 수 없는 항목

다음은 기능 또는 필드는 존재하지만 현재 관리자 화면에서 완전하게 설정할 수 없는 항목이다.

- SURVEY/QUIZ `RATING5`
- WPF `AUTO` 창 크기
- `hideDays` 사용자 지정
- `periodMode`와 반복 주기 관련 설정

또한 VIDEO의 일부 확장 스위치는 화면에는 있지만 WPF View에서 실제 동작까지 연결됐는지 옵션별 검증이 필요하다.

자세한 내용은 `POPUP_ADMIN_UI_GAP.md`를 참고한다.
